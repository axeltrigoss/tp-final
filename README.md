# Portfolio Web Personal - Trabajo Final UX/UI

Portfolio profesional desarrollado como trabajo final para la materia **Diseño UX-UI (2026)** de la Licenciatura en Sistemas de Información (Facultad de Ciencia y Tecnología - Sede Concepción del Uruguay, UADER).

## 🚀 Enlaces del Proyecto
* **Sitio Web Desplegado:** https://candid-kringle-305b5c.netlify.app/
* **Enlace a Figma (Research, Wireframes, Design System y Prototipo):** https://www.figma.com/design/bn8wLaGfZtg2nfAjBCNTte/Sin-t%C3%ADtulo?node-id=0-1&t=3L5PGgtMTFSYMtPK-1

## 🛠️ Tecnologías y Stack
* **HTML5 Semántico** con cumplimiento de normativas de accesibilidad WCAG 2.2 nivel AA.
* **CSS3** utilizando Variables CSS, Flexbox y CSS Grid (Enfoque Mobile-First).
* **JavaScript Vanilla** para la gestión interactiva del menú móvil de navegación y las ventanas modales de casos de estudio.

## 📂 Estructura de la One-Page
El sitio web cuenta con la estructura obligatoria de 9 secciones integradas por anclas:
1. **Header / Navegación:** Barra fija (sticky) con logotipo, links de ancla, indicador y menú responsive.
2. **Hero:** Presentación personal, propuesta de valor, badges de disponibilidad y zona horaria (UTC-3).
3. **Métricas / Highlights:** Cuadro de logros académicos y profesionales cuantificables.
4. **Skills:** Categorización de habilidades técnicas (Front-End, Back-End y Herramientas/DevOps) con chips.
5. **Proyectos:** Casos de estudio interactivos (incluyendo vista modal detallada de problemas, soluciones y resultados).
6. **Experiencia y Formación:** Línea de tiempo cronológica con hitos educativos y profesionales.
7. **Sobre mí:** Propuesta de identidad, retrato y principios de trabajo.
8. **Contacto:** Llamado a la acción directo con enlaces a redes profesionales y correo electrónico.
9. **Footer:** Pie de página con copyright, navegación repetida y créditos tecnológicos.

## 📈 Proceso UX/UI
* **Investigación:** Definición de proto-persona orientada a reclutadores del sector tecnológico y análisis de benchmark.
* **Concepto Visual:** Definición basada en la identidad visual propia, paleta de colores contrastada y tipografía limpia (*Inter*).
* **Validación:** Pruebas de usabilidad iterativas y maquetación fiel al prototipo de alta fidelidad diseñado en Figma.
